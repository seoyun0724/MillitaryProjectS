# 차량 외관 부품 인식 AI 개발 버전

목표: 차량 사진에서 외관 부품의 위치를 탐지하고 부품 이름표를 표시합니다. 타이어와 휠은 별도 클래스로 구분합니다. 손상 종류와 손상 정도는 현재 목표에 포함하지 않습니다. 사진 검토·부품 바운딩 박스 표시, YOLO 학습 데이터 내보내기, 전용 모델 추론 연결, JSON 탐지 보고서 기능을 구현했습니다. **렉스턴 스포츠와 코란도 전용 학습 모델은 아직 없습니다.**

## 실행

이 폴더에서 `python server.py`를 실행하고 브라우저에서 http://127.0.0.1:8765 를 여세요. Windows에서는 `start.cmd`를 더블 클릭해도 됩니다. 서버 종료는 터미널에서 Ctrl+C입니다. 화면·정답 데이터 구축에는 외부 패키지나 인터넷이 필요 없습니다. 상위 `차량 사진` 폴더의 사진을 읽으며 원본은 변경하지 않습니다.

1. 왼쪽에서 차종과 사진을 선택하고, 표시할 부품을 고른 뒤 드래그해 위치를 표시합니다.
2. 사진에서 분명히 보이는 부품을 표시하고 검토 완료·저장합니다. 가려졌거나 경계를 판단하기 어려운 부품은 억지로 표시하지 않습니다. 타이어는 고무 부분, 휠은 림/중앙 휠 부분으로 분리합니다.
3. 저장한 2장 이상으로 학습 데이터를 내보냅니다. 실제 학습에는 다양한 차량·각도·거리·조명에서 촬영한 사진이 필요합니다. 배경 사진도 포함하려면 표시 대상 부품이 없는지 확인한 뒤 빈 라벨로 저장합니다.
4. `data/annotations`의 수동 정답과 내보낸 데이터는 로컬에 저장됩니다. 백업해 주세요. AI 결과는 수동 정답을 덮어쓰지 않습니다.

## 모델 학습과 평가

학교 GPU 계정에 접속할 수 없으면 [Colab 학습 노트북](COLAB_TRAINING.ipynb)을 사용할 수 있습니다. `dataset_13class.zip`을 업로드하고 런타임 유형에서 GPU를 선택한 뒤 위에서부터 셀을 실행하세요. 무료 Colab GPU는 사용 가능 여부와 시간이 보장되지 않습니다. 현재 공개 학습 묶음은 17장(학습 15장, 검증 2장)으로 여전히 매우 작아, 학습 결과는 파이프라인 확인용으로만 보세요. 새로 추가한 웹 사진의 출처·각도는 `dataset/web_sources.json`, 내려받지 못한 후보는 `dataset/web_exclusions.json`에 기록했습니다.

Python 3.11 또는 3.12의 별도 가상환경 사용을 권장합니다. 현재 시스템의 Python 3.14에서 AI 의존성 설치·실행은 검증하지 않았습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-ai.txt
.\.venv\Scripts\python model.py train --vehicle rexton_sports --data "내보낸 data.yaml 절대 경로" --epochs 100 --device cpu
```

처음 학습 시 기본 YOLO 가중치를 내려받습니다. GPU 환경은 호환되는 PyTorch 설치 후 `--device 0`을 사용하세요. 학습 종료 후 `runs/rexton_sports*/weights/best.pt`를 이 폴더의 `models/rexton_sports/best.pt`로 복사하고, 같은 가상환경 Python으로 `server.py`를 실행하세요. `models` 폴더는 직접 만들어 주세요. 프로그램은 클래스가 다른 일반 차량 탐지 모델을 거부합니다.

```powershell
.\.venv\Scripts\python model.py validate --vehicle rexton_sports --data "별도 평가 데이터의 data.yaml 절대 경로"
.\.venv\Scripts\python server.py
```

내보내기의 약 80:20 분할은 개발용입니다. 같은 차량·같은 촬영 세션·유사 이미지가 학습/평가 양쪽에 들어가면 성능이 부풀려집니다. 최종 성능은 차량 또는 촬영 세션 단위로 분리한 미사용 데이터에서 부품별 precision/recall, mAP와 누락 사례를 확인하세요. 미검출은 ‘정상’ 판정이 아니라 해당 사진에서 학습 모델이 부품을 찾지 못했다는 뜻입니다.

## 분류 기준

이번 초기 학습의 부품 클래스와 화면 이름은 `server.py`의 `CLASSES`와 `LABELS` 목록이 기준입니다: 후드, 그릴, 범퍼, 앞유리, 창문, 헤드램프, 주간주행등, 타이어, 휠, 테일게이트, 도어, 후미등, 사이드미러. 펜더와 방향지시등은 시간 제약으로 이번 학습에서 제외했습니다.

주간주행등은 다른 램프와 독립 경계를 명확히 구분할 수 있는 경우에만 표시합니다. 테일게이트는 픽업 적재함의 뒷문입니다. 클래스 목록이나 순서를 바꾸면 기존 라벨과 모델을 함께 변환·재학습해야 합니다.

## 두 차종 별도 모델

화면에서 렉스턴 스포츠 또는 코란도를 먼저 선택하세요. 사진 목록은 공용이며 각 사진에 맞는 차종을 직접 선택합니다. 다른 차종으로 이미 저장한 사진의 중복 등록은 차단합니다. 정답과 내보내기 데이터는 data/rexton_sports와 data/korando로 분리합니다. 코란도 학습 명령은 --vehicle korando를 사용하며 결과를 models/korando/best.pt에 넣습니다. 각 차종에 대해 별도 데이터로 학습·평가를 실행해야 합니다. 현재 두 전용 모델 모두 미학습입니다. 차종 자동 식별은 구현 범위에 포함되지 않습니다.
